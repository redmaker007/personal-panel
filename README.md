# 个人属性面板 2.0 · 强项查找器

从具体经历中寻找一个本人可能未察觉的强项。5 根、25 叶的维度树保持不变。完整能力面板 1.0 已冻结，保留在 index.html。

## 当前题库：sf2.2

76 道题全部重写：25 道情境二选一、50 道行为验证题、1 道最终预测题。不是每个人都回答全部题库，实际约 40–56 题。

| 阶段 | 内容 | 规则 |
|---|---|---|
| A 情境选择 | 25 组二选一，两种反应均有价值 | 每叶恰好出现两次，左右各一次，两次至少间隔 7 题。未选项扣 3.5，两次未选累计扣 7；≤3 才出局 |
| B 经历核实 | 每个 A 幸存者一道具体行为题 | 不设跳过某个幸存者的题量上限；计分档位沿用 [-7,-5,-3,-1,+1] |
| C 重点确认 | 最多 5 个领先候选各一道不同经历题 | 补充第二条证据；没有可比经历可以不计分 |
| D 预测 | 全部 25 个候选在此时才呈现 | 只对照受测者的猜测，不参与计分或自动训练 |

二选一只提供相对偏好线索，未选不等于绝对能力弱。配对不能保证两项不同时弱，留下来的候选仍要通过 B 核实。
每叶起手 10 分，跑分 ≤3 出局。排名只使用可判断的行为证据，A 选中项不凭空加分。
行为题的“暂不判断”不扣分、不作为有效证据，也不纳入校准。若没有任何可判断经历，结果页明确不下结论。

完整题库和配对理由见 [sf2.2 完整题库](docs/sf2.2-完整题库.md)，方法、变更与限制见 [题库改版说明](docs/题库改版说明.md)。

## 打开

```powershell
cd server
npm install
Copy-Item .env.example .env  # 已有配置不要覆盖
# 首次使用时填写 .env 中的 ADMIN_PASSWORD
npm start
```

默认端口 4000，可由 .env 中 PORT 覆盖。当前本地安装使用 4108。
新版：`/v2.html` 或 `/`；后台：`/admin`；旧题库续答：`/v2-previous.html`；冻结 1.0：`/index.html`。
当前已接入 Node / Express / SQLite，并使用前后台共享模块，不再是可直接双击打开的单文件 HTML。
浏览器通过 localStorage 保存和离线续答，首次开始须连接一次服务取得题库对应的权重版本。

## 存档和后台

sf2.2 使用独立的设备存档与权重版本。sf2.1 的题目、引擎、存档、历史统计保留，可继续旧测验。
禁止把旧答案序号套进新题目；后台可切换题库，统计与自动训练样本不混用。
收集完整题库、逐题展示、选择、作答用时、返回修改、暂停/恢复、结果与反馈；断线队列按序幂等重试。
后台查看每题选项分布、未展示/展示未答/暂不判断、用时、事件记录、校准与回滚。

自动校准门槛、存储语义及接口见 [后台与体验说明](docs/新版升级说明.md)。每个题库的初始权重独立为 1；新题库不直接继承旧题目的已训练权重。

## 冻结版本的约束

1.0 的存档与选择压缩码依赖绝对题号。若将来修改其整题数量或顺序，必须同步递增 index.html 的 KEY 与 CODE_VER。本轮不改 index.html。
早期产品思路归档于 [旧版设计记录](docs/旧版设计记录.md)，其中 10 道五选一的 A 阶段已被当前方案取代。
