# 個人屬性面板

一個網頁測驗工具。做完一套選擇題，系統輸出一張「個人屬性面板」——類似 RPG 角色數值表，
把一個人拆成**硬件（身體類）與軟件（心智類）**兩大類、約 42 個維度，每個維度給 0–100 分，
再把這些維度按真實情境重新組合成 **93 件具體的事**（從吵架、專心讀書到搬家），
排出你在哪些事上吃得開、哪些吃力。

定位在「一眼看穿的娛樂測驗」和「學術心理量表」之間：直觀好懂，但靠交叉驗證換準確度。
核心初衷是**從「擅長應對什麼難題」倒推維度**，而不是從抽象人格特質出發。

## 打開

[`index.html`](index.html) 是一支完全靜態的單檔網站，**沒有建置步驟**——直接用瀏覽器開，
或丟到任何靜態主機。答案存在瀏覽器 `localStorage`，可以中斷續做；
結果頁能複製一段「選擇壓縮碼」，日後貼回去就還原整張面板。支援繁體中文 / English。

## 專案結構

```
index.html              測驗站本體：題庫、計分引擎、面板 / 雷達 / 稱號 / 場景，全寫在這一支
overview guide.txt      設計交接文件：維度設計三原則、題目格式規則、計分邏輯、注意事項
docs/
  準確率方法論.md         怎麼判斷題目好不好、怎麼把面板調準（四個可量測性質 + 改進優先序）
server/                  後台：題目編輯 + 題庫體檢（見 server/README.md）
```

## 測驗設計（見 `overview guide.txt`）

- 四個區塊：① 硬件客觀填空 ② 硬件情境自評 ③ 軟件情境題 ④ 交叉校驗。目前共 131 題。
- **一律 5 個選項**，中間檔容納「一般人」。區塊 ①②④ 選項按 A 最弱 → E 最強遞增；
  區塊 ③ 選項打亂、無明顯最優解。
- **零經驗門檻**：只問受測者必然有過的經驗，不預設健身過 / 學過樂器 / 當過主管。
- 一題可為多個維度加分；每個維度至少被 3 道題覆蓋以交叉驗證。
- 區塊 ④ 用不同角度重問前面的維度，偵測自評偏差（如全選最強選項）並回頭校正。

## 後台

[`server/`](server/) 是 Node + Express + SQLite（用 Node 22.5+ 內建的 `node:sqlite`，免原生編譯）：

- `npm run import` 把 `index.html` 的題庫解析進資料庫——**不複製文字**，改完題目重跑即可。
- 網頁介面編輯既有題目的內容（題幹、選項文字、維度加分、num 題範圍）。
- **題庫體檢**：一組不需作答資料的靜態指標（維度覆蓋、區塊三「無最優解」稽核、
  選項單調性、硬 / 軟件平衡…），呈現在「選項數據」頁。

```bash
cd server
npm install
npm run import
npm run dev      # 後台 http://localhost:4000/admin ・ 測驗站 http://localhost:4000/
```

細節見 [server/README.md](server/README.md)。

## 重要約束：改題與存檔版本

答案存檔（`localStorage`）與「選擇壓縮碼」都以**絕對題號**索引。

- **純內容編輯**（改題幹、改選項文字、改選項分數）→ 安全。
- **新增 / 刪除 / 換順序整題** → 會讓既有存檔整體位移、對到錯的題目上，
  必須同步遞增 `index.html` 裡的 `const KEY` 與 `const CODE_VER`。代價是作答到一半的
  使用者進度歸零、舊壓縮碼與歷史記錄從此打不開。

## 現況與方向

- `index.html` 的**完整面板版**（131 題 → 42 維度 → 93 個場景）可用，是目前的正式版本。
- **維度分類法正在重構**：從扁平的約 42 維整理成分層的樹（少數幾個根 → 分支 → 葉），
  每個葉盡量互斥（延續 guide 的「不可組合還原」原則）。未定案。
- 正在評估把測驗改成自適應的**「強項查找器」**：用類似 DFS 的方式、以較少題目
  （~30 題）只找出最擅長的 3–5 件事，並改用減分制（每個特質起手滿分，
  只有答出弱點才往下扣；沒問到的維持中性）。**還在設計階段，尚未進 repo。**
