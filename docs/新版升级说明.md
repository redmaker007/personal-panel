# 强项查找器新版

升级对象：v2.html 与现有 Node / Express / SQLite 后台。默认首页改为新版，旧 index.html 与旧版题库编辑、分析接口保留。本次没有发布到外部平台。

## 启动

在 server 目录执行 npm install，复制 .env.example 为 .env，填写 ADMIN_PASSWORD，再执行 npm run dev。
测验页 `/`，管理员登录 `/admin`。默认端口 4000，可用 `.env` 里的 `PORT` 覆盖，实际端口见启动日志。
未设置管理员密码时登录关闭，不再退回 changeme。已有 ADMIN_PASSWORD 配置可继续使用。
沿用现有架构，没有额外打包步骤。浏览器与 Node 共用 ES modules 数据/计分模块，新版不支持直接双击 HTML 文件。

## 体验

- 森林绿与香槟金的明暗主题，移动布局、键盘焦点、减少动态效果偏好。
- 先选择再确认，避免误触连答；1–5 或 A–E 选择，Enter 继续。
- 四阶段稳定进度；返回时从答案回放，恢复跨阶段顺序。
- 设备自动保存、暂停续答、离线队列、恢复连接后重试。开始新测验也保留之前未发送的事件。
- 保存/同步状态真实显示；设备存储不可用时提示。其他标签页修改存档时停止当前编辑，提示刷新。
- 新题库使用独立存档；sf2.v1 和 sf2.1 可从旧题库入口恢复，不将旧答案改解释成新题目。
- 结果引用本人回答；正向证据不足时只显示待验证方向。支持文本导出、打印/PDF和结果反馈。

## 采集与统计

当前题库 sf2.2：76 道题、25 个变量；A 为 25 道情境二选一，B/C 为 50 道行为题，D 为 1 道预测题。未展示的题也完整存档。

| 表 | 内容 |
|---|---|
| sf_catalog | 题库版本、题干、全部选项和变量映射快照 |
| sf_sessions | 匿名浏览器标识、状态、题库/权重版本、当前答案、结果、反馈、时间 |
| sf_events | 按序只追加的展示/作答/返回/暂停/恢复/反馈事件；原请求与服务端生成的题干、选项、变量、基础分值 |
| sf_answers | 每会话每题当前有效答案；撤销不会删除事件历史 |
| sf_weight_versions | 不可变权重版本、原因、分析报告 |
| sf_settings | 当前版本、自动调权开关、上次分析和样本计数 |

展示按「会话 + 题目」去重，选项分布仅统计当前有效答案。展示未答包括返回后撤销答案；未展示不能解释成能力低。
用时仅累计页面可见时间，最大一小时。它来自客户端，不是防作弊证据。
请求使用会话写入凭证、严格序号、幂等重试和整批事务；乱序、内容不同的重复请求会拒绝，不重复增加统计。
后台统计/导出须登录；写入令牌只保存哈希，导出不包含令牌或匿名设备标识。
不保存姓名、联系方式、原始 IP、User-Agent 或设备指纹。限流按连接地址的**加盐** SHA-256 计数（盐取自 RATE_LIMIT_SALT，未设置则首次运行时生成并存入 sf_settings）；只加密不加盐是不够的——IPv4 全空间仅 2^32，可被穷举反查。客户端标识是浏览器本地生成的随机 UUID，跨会话持久，但不对应任何账号。

## 自动调权

原始淘汰逻辑保留：起手 10 分，A 的未选项每次扣 3.5（两次共扣 7），行为题变化 [-7,-5,-3,-1,+1]，跑分 ≤3 淘汰。
排名只包含至少有一道行为题的变量，筛选题不算正向证据。
变量权重 w 控制证据偏离中点的程度：排名值 = 7 + (行为题基础平均值 - 7) × w。
初始 w=1；低可靠性的证据向中点收缩。不会自动改题干、选项语义、基础分值方向或淘汰阈值。

每次完成测验自动分析，也可在后台立即分析：

1. 每个匿名浏览器只取当前题库最近一份完成记录。
2. 配对同一变量的 B/C 两道行为题，排除任一题低于 750ms，以及全部行为题选同一档的测验。
3. 计算 Pearson 相关；无变异时不调整。
4. 至少 40 个有效配对，且较上次该变量应用调整时新增至少 20 个配对。
5. 用 n/(n+100) 收缩相关性相对 0.4 的偏离；每次变化不超过 0.025，总权重 [0.85,1.15]。
6. 生成新权重版本与完整报告；只供新测验使用，旧会话锁定原版本。
7. 回滚产生新版本并暂停自动调整。

这是保守的一致性校准，不是监督学习的准确率优化。自适应出题会使第二题的样本偏向领先候选，收集充分配对可能较慢。无外部标准答案，不能据此证明效度提升。
预测与结果反馈不当作正确答案训练。匿名浏览器去重不等同身份认证，换浏览器仍可能重复。

## 后台与接口

/admin 提供全部题目统计、25 个变量分析、分页会话导出、完整事件详情及版本回滚。

| 接口 | 行为 |
|---|---|
| GET /api/strength/config | 公开题库版本和当前权重 |
| POST /api/strength/sessions | 幂等创建、锁定版本 |
| POST /api/strength/sessions/:id/events | Bearer 令牌；每批 1–60 个事件，每会话最多 2000 个 |
| GET /api/strength-admin/summary | 全部统计与分析 |
| GET /api/strength-admin/sessions?limit=25&offset=0 | 分页记录，单页最多 100 份 |
| GET /api/strength-admin/sessions/:id | 完整事件及答案 |
| POST /api/strength-admin/analyze | 立即分析 |
| PUT /api/strength-admin/automatic | enabled 布尔开关 |
| POST /api/strength-admin/rollback | version 目标版本号 |

题库内容变更须递增 assets/sf-data.mjs 的 CATALOG_VERSION；历史快照和 sf2.1 引擎保留，旧会话继续按旧规则接收事件，新旧统计与校准分开。权重版本不能覆盖。
SQLite 增量新增 sf_* 表，不删除旧题库或旧提交记录。默认保留全部事件，没有自动清理。
服务只静态提供明确允许的页面与 assets，不再开放项目、配置和数据库目录。
